# Café & Sabor ☕

Este proyecto corresponde a una **pre-entrega del curso de Frontend y JavaScript**.

Para esta propuesta elegí desarrollar el sitio web de una cafetería ficticia llamada **Café & Sabor**. Elegí esta temática porque me permitía trabajar una propuesta visual cálida y desarrollar diferentes tipos de contenido, como productos, categorías y un formulario de contacto.

La idea fue crear un sitio sencillo, agradable y fácil de recorrer, donde se puedan conocer los productos de la cafetería y enviar consultas a través de un formulario.

## ¿Qué tiene el sitio?

El sitio está dividido en tres páginas:

* **Inicio:** presentación de la cafetería, información sobre nosotros y productos destacados.
* **Productos:** catálogo organizado por categorías: cafés, desayunos y brunch, dulces y otras bebidas.
* **Contacto:** formulario para enviar consultas.

## Tecnologías utilizadas

* HTML5
* CSS3
* Flexbox
* Google Fonts
* Formspree
* Live Server

## Características del proyecto

* Se utilizó **HTML semántico** para organizar el contenido.
* Se utilizó un archivo **CSS externo** para los estilos.
* Se incorporó **Google Fonts** utilizando la fuente Poppins.
* Se utilizó una **imagen de fondo** en la página de inicio.
* Se incorporaron imágenes para presentar los productos.
* Se utilizó **Flexbox** para organizar diferentes secciones y elementos.
* El sitio es **responsive** y cuenta con una adaptación para pantallas de hasta 600px.
* Se incorporó un formulario de contacto conectado con **Formspree**.
* Se probaron los enlaces de navegación y el envío del formulario durante el desarrollo.

## Diseño

Para el diseño elegí una paleta inspirada en el café, utilizando tonos marrones, crema y beige.

También busqué que la navegación, las tarjetas de productos y el formulario fueran claros y fáciles de utilizar.

## Formulario de contacto

El formulario se encuentra en la página **Contacto** y utiliza Formspree para recibir los mensajes enviados.

Cuenta con los siguientes campos:

* Nombre
* Correo electrónico
* Mensaje

El formulario fue probado durante el desarrollo y se comprobó que los mensajes se reciben correctamente.
